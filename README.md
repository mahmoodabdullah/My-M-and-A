# Welcome to My M And A
***

## Task
The challenge was to clean and merge three customer CSV files that had different formats and inconsistent data.

## Description
I used Python and Pandas to clean the customer data, fix formatting issues, and merge everything into one DataFrame.

## Installation
Install Python and Pandas using pip install pandas. SQLite is already included with Python.

## Usage
Run the Python file to read, clean, and merge the three CSV files into one customer database.
python my_m_and_a.py
